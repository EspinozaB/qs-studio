# Changelog

QS Studio shows the sections newer than the version you have when it offers an update. Newest first.

## 0.8.0
- Setup guide for new users: connect the QS, back it up, then the main pages. Shown on first start; reopen it with
  Setup guide at the bottom of the sidebar.
- Check for updates (Updates... in the sidebar): shows what changed and updates only when you click Update now. Your
  "QS Studio Data" folder (settings, libraries, backups) is never touched. Can check once a day at startup; you can turn
  that off in the same menu.
- Sidebar in four sections: Play, Edit, Library (Backup & Restore, Move banks, Cards & ROM) and Synth (Connection,
  Global Settings, Check-up, Record & Sample).
- Shorter text on every page. The longer explanations are in How this works (top right) and in the tooltips.
- Check-up: reply times in whole milliseconds, keyboard curve and A-D controller mode named as on the QS, program cards
  reported as program cards.

## 0.7.0
- Undo and redo in the Program, Mix and Effects editors.
- Program Editor Tools: copy, paste, swap and reset sounds; new program; randomize; blend two programs.
- Mix Editor channel tools: copy, paste and swap channels.
- Search everything saved (libraries, backups, .syx files); drag a User program onto another to swap them.
- Aftertouch: on-screen Pressure slider, a switch to block a controller's aftertouch, and a MIDI monitor for key and pad
  velocities.
- Build a QS card image from WAV files (Cards & ROM). Untested on hardware.
- Check-up page: model, OS version, MIDI link test, Global settings explained, User bank and card slot.

## 0.6.2
- Sound Player: fixed the whine and build-up when playing several notes; Decay and Sustain controls.

## 0.6.1
- Card images: byte order check and an output limiter; mixes play every keyboard channel from QS Studio's keys; the
  Effects Editor explains the configuration in use.

## 0.6.0
- Sound Player and the QS Sound Player plugin (VST3, AU, LV2, standalone); builds for Windows, macOS and Linux;
  regrouped Effects Editor; steadier mix switching.
